# Blinkit Clone — Full-Stack MERN Application

A full-stack grocery delivery web application inspired by Blinkit, built to explore modern frontend and backend web development.

## Overview

This project contains a client-side application and a server-side application organized into separate folders. It demonstrates a full-stack web development workflow using JavaScript technologies.

## Tech Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- Add the database name after verifying the backend configuration.

## Getting Started

### Prerequisites
- Node.js and npm installed

### Run the frontend

```bash
cd client
npm install
npm run dev
```

### Run the backend

Open a separate terminal:

```bash
cd server
npm install
```

Check `server/package.json` for the available start script before starting the backend.

## Environment Variables

Configure the required environment variables locally using a `.env` file in the server directory. Never commit passwords, API keys, database credentials, or other secrets.
